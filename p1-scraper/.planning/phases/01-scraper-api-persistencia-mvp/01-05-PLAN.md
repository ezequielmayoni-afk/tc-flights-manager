  <action>
Create `src/run-scrape.ts`:
- Import the five pipeline modules above (`.js` specifiers) plus `import { supabase } from './supabase.js'`.
- `const dry = process.argv.includes('--dry')`.
- `async function main()`:
  - `console.log('[run] mode=' + (dry ? 'dry' : 'real'))`.
  - `const events = await scrapeListing()`; `console.log('[run] discovered ' + events.length + ' F1 events')`.
  - Counters: `let ok = 0, skipped = 0`. Track seen events: `const seenUuids = new Set<string>()`.
  - For each `listingEvent` of events, wrap in try/catch:
    - `const pair = await resolveUuid(listingEvent.url)`. If `!pair` → `skipped++; continue` (warn already logged in resolveUuid).
    - `const data = await getEvent(pair.eventUuid, pair.categoryUuid)`.
    - `const normalized = normalizeEvent(data, { eventUuid: pair.eventUuid, sourceUrl: listingEvent.url, slug: listingEvent.slug })`. If `!normalized` → `skipped++; continue`.
    - `seenUuids.add(pair.eventUuid)` (only count an event as "seen" once it normalized successfully).
    - If `dry` → `await dryPrintEvent(normalized)` else `await persistEvent(normalized)`.
    - `ok++`.
    - On catch: `console.warn('[run] skipping ' + listingEvent.url + ': ' + err); skipped++` (SCRAPE-06 — one bad event never aborts the run).
  - RUN-LEVEL availability sweep (DATA-04 — events that vanished from the listing entirely):
    - Skip this block entirely when `dry` (no DB writes) and when `seenUuids.size === 0` (don't deactivate everything on a failed run).
    - Build the PostgREST `in` filter with quoted UUIDs: `const seenList = '(' + [...seenUuids].map(u => '"' + u + '"').join(',') + ')'`.
    - Mark unseen events inactive: `await supabase.from('p1_events').update({ active: false, updated_at: new Date().toISOString() }).not('event_uuid', 'in', seenList)`. On error, `console.warn`.
    - Mark their tickets unavailable. Either join via the deactivated event ids or, simpler: first fetch the ids of now-inactive events — `const { data: gone } = await supabase.from('p1_events').select('id').eq('active', false)` — then if `gone?.length`, `await supabase.from('p1_tickets').update({ availability: 'unavailable', updated_at: new Date().toISOString() }).in('event_id', gone.map(g => g.id))`. On error, `console.warn`. Never delete rows.
    - `console.log('[run] run-level sweep: deactivated events not seen this run')`.
  - `console.log('[run] done — ok=' + ok + ' skipped=' + skipped + (dry ? ' (no DB writes)' : ''))`.
- Call `main().catch(err => { console.error('[run] fatal', err); process.exit(1); })`.
- No ESM entrypoint guard required (tsx runs the file directly); just call main() at module top level.
