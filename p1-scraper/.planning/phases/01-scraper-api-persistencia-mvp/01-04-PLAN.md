  - Upsert the event into `p1_events` with `onConflict: 'event_uuid'`, setting all event columns plus `active: true`, `last_seen_at: new Date().toISOString()`, `updated_at: new Date().toISOString()`.   - For each normalized ticket, build a row with `event_id` (the id just returned), `category_id`, `name`, `description`, `seatplan_image_url`, `price`, `currency`, `features` (jsonb), `delivery_type`, `availability: 'available'`, `last_seen_at`/`updated_at` = now.   - Per-event availability sweep (part of DATA-04): collect `const currentCategoryIds = ev.tickets.map(t => t.category_id)`.
