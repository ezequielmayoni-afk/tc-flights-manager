    `import type { NormalizedEvent } from './p1/normalize.js'`).

    Constant: `const BUCKET = 'p1-images'`.

    Export `async function ensureBucket(): Promise<void>` — idempotently ensure the
    public bucket exists. Implement as:
      `const { error } = await supabase.storage.createBucket(BUCKET, { public: true })`
    Treat an "already exists" error (error?.message contains 'already exists', or
    a 409 / 'Duplicate') as success — log `[images] bucket p1-images ready` and
    return. Any OTHER error: `console.warn('[images] could not ensure bucket: ' + error.message)`
    and return (do not throw — if the bucket was created manually in the dashboard,
    uploads still work). Call ensureBucket() once at the start of mirrorEventImages
    guarded by a module-level boolean so it only runs once per process.

    Export `async function uploadImage(url: string, storagePath: string): Promise<string | null>`:
      - `const res = await fetch(url, { headers: { 'User-Agent': BROWSER_UA } })`
      - if `!res.ok` → `console.warn('[images] fetch ' + res.status + ' for ' + url)`; return null
      - `const bytes = new Uint8Array(await res.arrayBuffer())`
      - derive contentType from `res.headers.get('content-type')` falling back to 'image/jpeg'
      - `const { error } = await supabase.storage.from(BUCKET).upload(storagePath, bytes, { contentType, upsert: true })`
        (upsert:true makes re-runs idempotent — same deterministic path overwrites)
      - if error → `console.warn('[images] upload failed ' + storagePath + ': ' + error.message)`; return null
      - on success return storagePath
      - wrap the whole body in try/catch; on any throw warn and return null (per-image tolerance — never propagate)
      - `await new Promise((r) => setTimeout(r, THROTTLE_MS))` before returning to throttle

    Export `async function mirrorEventImages(ev: NormalizedEvent): Promise<void>`:
      - call `await ensureBucket()` (once-guarded as above)
      - resolve the event id once: `const { data: row } = await supabase.from('p1_events').select('id').eq('event_uuid', ev.event_uuid).single()`.
        If no row → `console.warn('[images] no p1_events row for ' + ev.event_uuid)`; return.
      - Event main image: if `ev.main_image_url`, call uploadImage(ev.main_image_url, `events/${ev.event_uuid}.jpg`).
        If it returns a path, `await supabase.from('p1_events').update({ main_image_storage_path: path }).eq('event_uuid', ev.event_uuid)` (warn on error, continue).
      - Each ticket with `seatplan_image_url`: uploadImage(url, `tickets/${ev.event_uuid}/${t.category_id}.jpg`).
        If it returns a path, update p1_tickets:
        `await supabase.from('p1_tickets').update({ seatplan_image_storage_path: path }).eq('event_id', row.id).eq('category_id', t.category_id)` (warn on error, continue).
      - End with `console.log('[images] mirrored ' + ev.name)`.

    Defensive throughout: any single image failure warns and the loop continues —
    one bad image never aborts the event, and one bad event never aborts the run.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| p1travel S3 → scraper | image bytes fetched from an untrusted external host |
| scraper → Supabase Storage | service-role upload into a public bucket |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | uploadImage fetch of remote image | accept | Bytes are public catalog images displayed to buyers, not executed. Content-type defaults to image/jpeg; bucket only serves static images. Low value target. |
| T-02-02 | Denial of Service | unbounded image downloads per run | mitigate | THROTTLE_MS delay between uploads; per-image failure is caught and skipped so a hanging/huge image cannot abort the run. |
| T-02-03 | Information disclosure | public p1-images bucket | accept | Bucket holds only public marketing/seatplan images already public on p1travel.com; no PII. Public read is required for TC to consume stable URLs. |
| T-02-04 | Elevation of privilege | service-role key in scraper process | mitigate | Key inherited from ../.env.local (gitignored), never logged, runs server-side only — same posture as existing supabase.ts. |
</threat_model>
